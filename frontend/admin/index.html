Google Workspace Directory API Flow

In Real API Mode, the system dynamically checks the specified Google Group membership when a guard logs in via Google OAuth.

An automated background sync job runs every 1 minute to fetch all members from the group, auto-provision newly added guards, and deactivate guards removed from the group, terminating their active sessions instantly.

🔑 Setup instructions:
  1. Create a Google Group in your Workspace admin console.
  2. Create a GCP project and enable the Admin SDK API.
  3. Create a Service Account and download the JSON key.
  4. Paste the JSON key contents into the text area on the left.
